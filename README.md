# FM Reception with the GNU Radio Companion

## Source:
* https://www.nutsvolts.com/magazine/article/fm-reception-with-the-gnu-radio-companion
* https://www.nutsvolts.com/uploads/magazine_downloads/202002-Post.zip

## Introduction:
This repository contains the files that accompany the article written by John E. Post
in the Nuts and Volts magazine in 2020. The original files (in the initial commit) are
written for an older version of GNU Radio and when opened in the current (v3.10) version
show many missing blocks, which makes understanding their purpose difficult.

The intent is to translate each of the flowgraphs to the current version of GNU Radio
whilst maintaining the intent of their original.

I note that John's article is an excellent resource in discovering how FM reception
works and it includes decoders for most (if not all) sub-carriers, including stereo,
RDS and SCA.

Thank you John!


## Conversion:
Using [GNU Radio Companion File Converter](https://github.com/khanfar/GNU-RADIO-converter)
the flowgraphs were translated from v3.7 to v3.10. Note that this is an initial translation
only, there are still missing blocks at this time.

Thank you M Khanfar!
